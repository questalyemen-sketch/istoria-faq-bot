# iStoria FAQ Bot

Telegram bot for answering frequently asked questions about the iStoria English learning app.

## Features

- FAQ answering
- Smart question matching
- Arabic question normalization
- iStoria knowledge base
- Admin panel
- Add questions from Telegram
- Delete questions
- FAQ statistics
- SQLite database
- Railway-ready deployment

## Environment Variables

The bot requires:

- `BOT_TOKEN`
- `ADMIN_IDS`

Example:

```env
BOT_TOKEN=your_bot_token
ADMIN_IDS=123456789
